# Saeed Ahmad, Portfolio

Dual-purpose portfolio for **freelance (Upwork)** and **full-time job** applications.

## Highlights

- Editorial "studio" design: warm paper palette, kinetic display type, film grain
- Custom-shader 3D iridescent blob in the hero (R3F) that morphs and follows the cursor
- Preloader, custom cursor, magnetic buttons, Lenis smooth scroll, scroll-scrubbed text
- Project cards with live-site screenshots and URLs (EventZero, BrandPulse, ProfitPilot, SmartFaktura, …)
- Work history: Solutionsloft, NTDC, Intelliscence
- Delivery-proof outcomes from real engagements (no fake quotes)

## Run

```bash
cd f-portfolio-3d
npm install
npm run dev
```
